    01

    Project

    Create a project.

    Create a project for the story you want to write:

    1. Click the Breadmaker button.
    2. Click New Project….
    3. Enter a project name.
    4. Click Create.

    Use Switch Project → Browse All Projects to find another book. The pencil beside the project name renames it. For an existing file, see Import.

    02

    Manuscript

    Add a chapter.

    1. Open Manuscript.
    2. Open ⋮ beside Full Text, then click Add Chapter.
    3. Rename the chapter.
    4. Write in the page.

    The Manuscript toolbar also holds Notes, Markers, Images, Cuts, and Narration. Use the bookmark beside the page to return to your place. These stay beside the draft as you write and revise.

    03

    Canvas

    Create a Canvas Card.

    1. Open Canvas.
    2. Create a Canvas.
    3. Click Add Card, then choose a Card.
    4. Place the Card, then type its title and notes.

    Select Cards to edit their details or connect them. Drag on empty space to select multiple items; Space-drag or right-drag pans. On touchscreens, drag empty space to pan. See Populate and Structure Versions for larger plans.

    04

    Maps

    Create a Map.

    1. Open Maps.
    2. Click + in the Maps sidebar.
    3. Open the Map’s ⋮ menu, then click New Line.
    4. Right-click the Line to add a Station or Span.

    Use a Station for a point and a Span for a stretch of the story. Junctions connect Lines. Select an item to edit its details and links; use Map view controls for scale and labels.

    05

    Tasks

    Create a Task.

    1. Open Tasks.
    2. Click + Task.
    3. Enter the task.
    4. Click Create.

    Open the Task to add details, links, and milestones for smaller steps. Mark work complete as you finish it.

    06

    Links

    Add a link.

    1. Open the details of a Task, Canvas Card, or Map item and click Add link.
    2. Choose what it should link to.
    3. Click Add link.
    07

    Checkpoints

    Create a Checkpoint.

    1. Open Manuscript.
    2. Click the Checkpoints icon.
    3. Click + Checkpoint.
    4. Choose the chapter or entire book, then click Create checkpoint.

    Select a saved Checkpoint to inspect it, compare it with the current draft, or use its export and restore actions. Review the scope and restore confirmation before applying changes.

    08

    Editor’s Eye

    Use Editor’s Eye.

    1. Open Manuscript.
    2. Click the eye icon.
    3. Click it again to return to the normal manuscript view.
    4. Turn it on again for a different font, color, spacing, and page layout. Your text stays the same.
    09 · Written guide

    Reviews

    Set up a Review.

    1. Open Reviews, then click Create Review.
    2. Name it and choose the scope: the entire manuscript, selected Chapters, or selected Scenes.
    3. Choose permissions for reading, comments and highlights, suggestions, or feedback, then click Create.
    4. Use Participants and Questionnaires to prepare the round.
    5. Click Start Review…, read the confirmation, then Start Review.

    Starting a round freezes what reviewers see and creates Checkpoints. Later manuscript edits do not change that round’s snapshot. Use the Review’s participant and round controls to manage feedback, and inspect comments and suggestions before applying changes. Portable Review exchange is separate from a project backup.

    10 · Written guide

    Targets

    Choose your own pace.

    1. Open the Breadmaker menu, then Targets….
    2. Turn on Enable targets and click + Add target.
    3. Choose a measure: words, characters, time in app, or active time.
    4. Choose Daily, Weekly, or Monthly, enter the target, and click Save.
    5. Open Targets again to adjust a goal, choose an optional chime, or view History….

    What counts?

    Words and characters measure net manuscript changes. Deleting text can reduce progress. Time in app counts foreground time; active time pauses after inactivity.

    Targets starts off. Turning it off stops new tracking and keeps saved goals and history. Each project has its own goals.

    11 · Written guide

    Languages

    Choose an interface language.

    1. Open the Breadmaker menu.
    2. Choose Language….
    3. Search or select a language in the list.

    This changes menus, labels, and messages. It does not translate your manuscript. Narration voice lists normally follow the interface language; use Narration settings to choose a voice or show all languages.

    Seven interface languages

    • English
    • Español Spanish
    • Français French
    • Italiano Italian
    • 日本語 Japanese
    • Português (Brasil) Brazilian Portuguese
    • 简体中文 Simplified Chinese

    Writing · Written guide

    Chapters, Scenes, and Tabs

    1. Use the Manuscript navigator to open a Chapter or Full Text. The navigator’s ⋮ menu lets you show Chapters or Scenes.
    2. Select a passage and choose Scene in the selection toolbar to work with a smaller section. Use a Chapter or Scene’s menu for its available actions.
    3. Use the Tabs menu to create a New Tab or Import Tabs…. A Tab’s menu includes Details and, for an additional document, Set as Main Manuscript.

    Organize a long draft and keep other documents in the same project.

    Use Chapter details for its title and other information. Keep research or alternate material in additional Tabs rather than mixing it into the Main Manuscript.

    Writing · Written guide

    Format text and change the view

    1. Select manuscript text to reveal its toolbar. Apply bold, italic, underline, or the available paragraph style.
    2. Open View in Manuscript to adjust the manuscript font, text size, and visible writing aids.
    3. Use the app’s theme control to choose the available appearance. Presentation settings do not replace your manuscript text.

    Adjust prose styling and the writing surface.

    For a temporary unfamiliar reading layout, use Editor’s Eye. For fewer surrounding controls, use Focus Mode.

    Writing · Written guide

    Notes and comments

    1. Select the relevant text in Manuscript and choose Comment. Write the note and submit it.
    2. Open Notes from the Manuscript toolbar to browse comments and return to their passages.
    3. Use the note’s available actions when you need to edit or remove it.

    Keep a note beside a passage or gather comments in one place.

    Comments in your working manuscript are separate from a frozen Review round. Choose Reviews when you want feedback on a fixed version.

    Revision · Written guide

    Markers and highlights

    1. Select text, then choose Highlight and a Marker, or create a new Marker.
    2. Open Markers in the Manuscript toolbar to manage the markers and find their passages.
    3. Use a Marker’s menu to change its visibility. Hiding a Marker changes the display without deleting its annotations.

    Mark passages for characters, themes, or an editing pass.

    Use your own Marker names to distinguish types of revision. The optional local Editor Highlights tools are separate from manually marking text.

    Writing · Written guide

    Images in the manuscript

    1. Open Images in the Manuscript toolbar and use its image action to choose a file.
    2. Select the image to adjust its size, caption, or description in the image controls. You can also replace the file.
    3. In Breadmaker Cloud, use a supported PNG, JPEG, or WebP file. If a file is rejected, check its format and size.

    Insert and manage pictures alongside prose.

    Keep an original copy of important artwork. Image handling and limits can differ between the local editor and Breadmaker Cloud.

    Revision · Written guide

    Find and replace

    1. Open View → Find / Replace in Manuscript. Enter text, then use the previous and next controls to visit matches.
    2. Choose case-sensitive or whole-word matching when needed. The active Manuscript view determines the search scope.
    3. Expand the replacement options to replace one match or preview and confirm Replace All.

    Search the draft, step through matches, and replace text.

    Open Full Text to search across the active document. This guide’s forgiving keyword search is separate from Find inside your manuscript.

    Writing · Written guide

    Focus, bookmarks, and split view

    1. Turn on Focus Mode from Manuscript’s View menu when you want fewer surrounding controls. Use its exit control to return.
    2. Select text and use the bookmark action, or bookmark a Chapter from its menu. Use the toolbar bookmark to return to that place.
    3. Open a Chapter’s menu and choose Split View to read it beside your current work. Close the split pane when finished.

    Reduce distractions, return to your place, or read two parts side by side.

    The project bookmark is a return point. Checkpoints are saved versions, and serve a different purpose.

    Audio · Written guide

    Narrate your manuscript

    1. Open Manuscript, then Narration in its toolbar. On a phone, find it in the Manuscript tools menu.
    2. Choose a Narrator voice. Select text and choose Narrate selection, or choose Narrate chapter. In Full Text, the scope action becomes Narrate book.
    3. Keep Breadmaker open while it prepares and saves the audio. Use Play/Pause, the position slider, the five-second skip controls, or playback speed to listen.
    4. To prepare audio without listening, open ⋮ beside the narration action and choose Generate selection, Generate chapter, or Generate book. Use Stop after this passage to finish the current passage before stopping.

    Listen to a selection, a chapter, or the whole book.

    Completed passages are saved as they finish. Keep the computer awake for a long generation. If playback does not start automatically, press Play.

    After editing narrated text, a recording can show Text changed. Use its Recreate recording action, or the scope menu’s Regenerate action, to record the new wording.

    Audio · Written guide

    Choose voices and narration settings

    1. Open Breadmaker → Project Settings… → Narration settings. Choose a voice or open Browse voices….
    2. Search the voice library, preview a sample, and enable the voices you want in the panel. Use Show voices from all languages to look beyond the current interface language.
    3. Adjust playback speed and pitch, generation pace, punctuation pauses, or passage and spoken-word highlighting. Click Save to apply the settings.

    Browse voices and adjust playback, generation, and highlights.

    Playback speed and pitch change listening only. Generation pace, punctuation pauses, and a different voice apply to new recordings; regenerate saved audio when you want those changes included.

    Voice and model downloads need internet. Local installed voices can work offline; Breadmaker Cloud still needs its normal connection and sign-in. Optional GPU acceleration can require a model download and falls back to CPU when unavailable.

    Audio · Written guide

    Download narration as WAV

    1. Generate the audio you want to keep, and recreate any recordings whose text has changed.
    2. Open Breadmaker → Project Settings… → Narration settings → Download audio….
    3. Choose Selection, Chapter, or Entire book, then Download WAV. For an excerpt, select whole words.

    Export saved audio for a selection, chapter, or entire book.

    The download combines saved recordings into one WAV file. It does not generate missing passages, and playback speed or pitch changes are not baked into the file.

    If audio is missing, generate it first. If a whole-book WAV is too large, download individual chapters. This is a WAV export, not an MP3 encoder.

    Files · Written guide

    Import a manuscript or project

    1. Open Breadmaker → Import → Manuscript… and choose a .docx, .doc, or .txt file. If an older .doc cannot be read, convert it to .docx and try again.
    2. For a DOCX document, choose which heading level marks Chapters. Read the destination choices before continuing.
    3. In Breadmaker Cloud, choose the separate-project destination. Replacing the current manuscript and appending Tabs are currently unavailable there. The local editor also offers those destinations when applicable.
    4. To import an exported project instead, use Import → Breadmaker Project… or Import JSON…. Import → Cuts… brings in a Cuts export.

    Bring in DOCX or plain text, or reopen a Breadmaker export.

    Wait for the import to finish before switching projects. A new-project import preserves the current book. Pre-alpha versions can reject incompatible older project formats.

    Files · Written guide

    Export your writing and project

    1. Open Breadmaker → Export. Choose Manuscript as DOCX or Manuscript as PDF… for a reading or editing copy.
    2. Choose Breadmaker Project for a portable project package, or JSON Project for the JSON format. Use Readable ZIP for a browsable archive of the available project material.
    3. Use Cuts to export the material kept in Cuts. Narration has its own Download audio action.

    Download a reading copy or a portable project.

    Reading formats and project packages serve different purposes. Check the exported file before relying on it as your only copy, and keep a separate backup of important work.

    Recovery · Written guide

    Keep removed text in Cuts

    1. Select manuscript text and choose Cuts, or use a Chapter’s Cut action.
    2. Open Cuts from the Manuscript toolbar to inspect the saved material and its available restore or reuse actions.
    3. Use Breadmaker → Export → Cuts to keep a separate Cuts file, or Import → Cuts… to bring one in.

    Set aside passages or chapters without losing the idea.

    Cut and Delete are different actions. A Chapter’s Delete action does not create a Cut. For other recovery options, see History and Undo.

    Recovery · Written guide

    History, Undo, and recovery

    1. Use the app’s Undo and Redo controls for recent changes in the working session.
    2. Open Breadmaker → Project Settings… → History to browse available automatic recovery states and their compare, export, or restore actions.
    3. Use Checkpoints when you want to save a named, deliberate version before a revision. Read any restore preview and confirmation before applying it.

    Find automatic recovery states and distinguish them from Checkpoints.

    Session Undo is for recent changes. Use Checkpoints for versions you want to revisit, and exports or backups for separate copies. A closed session’s Undo list and older recovery states may no longer be available.

    Recovery · Written guide

    Backups, verification, and Trash

    1. Open Breadmaker → Project Settings… and find Backup locations, Recovery Backups, Project Trash, or Verify Project, where available.
    2. In the local editor, add an available local or synced folder, Google Drive, or WebDAV location and set its retention. Remote destinations need their connection setup. Keep backups somewhere separate from your working project.
    3. For recovery, inspect the available backup and its confirmation. Recovery Backups restore into a separate project. Use Trash to inspect recoverable deleted projects.

    Manage available recovery tools and check important copies.

    Backup options differ between the local editor and Breadmaker Cloud. Keep a separate export of important work.

    Permanent erasure is different from recoverable Trash. Read destructive confirmations carefully and export a verified copy first when you need one.

    Planning · Written guide

    Populate plans and Structure Versions

    1. Open the Canvas or Map menu and look for Populate. Choose the available manuscript source or story template.
    2. On Canvas, use the structure tools to arrange the plan and manage Structure Versions. Select the saved version you want to inspect.
    3. If applying structure back to the manuscript, review the preview and confirmation before making the change.

    Start a Canvas or Map from existing structure or a template.

    Creating a plan and applying it to the manuscript are separate steps. Save a Checkpoint before a substantial structural revision.

    Preferences · Written guide

    Experimental tools and availability

    1. Open Breadmaker → Project Settings… → Experimental Features to see optional unfinished tools for this project. These start off.
    2. The local editor can expose Editor Highlights for targeted editing searches. Maps also has an experimental renderer. Enable only the tools you want to try.
    3. Use Project Settings → Metadata for project counts and structure information. Use the profile/account controls for hosted account settings, where available.

    Know which tools are optional and which edition you are using.

    The local editor is accountless and works offline after setup. Breadmaker Cloud needs an approved alpha account and an internet connection. Public local installers are still in release testing.

    Experimental tools can change and are optional. Availability can differ between the local editor and Breadmaker Cloud.
